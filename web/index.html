Capabilities

Engine Architecture & Features

Built for reliability, developer ergonomics, and high throughput without unnecessary complexity.

Pure Python Stream Decryptor

Natively reverses SaturnCDN's obfuscated player playlists and tokenized stream locations in pure Python without launching Chrome or Node processes.

Concurrent HLS Downloader

Fetches fragmented .ts video chunks across multiple worker threads, automatically selects highest bitrate variants, and stitches valid, playable media files.

Dynamic Multi-Domain Failover

Connects to animesaturn.me to auto-discover active mirror domains and select the fastest server, shielding your integration from DNS blocks and ISP filters.

Pythonic Interface & CLI

Natural indexing like anime[1], rich objects (Anime, Episodio, Server), and full terminal command-line tool with clean cancellation.
