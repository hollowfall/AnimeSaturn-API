Features

Designed for performance, developer ergonomics, and reliability without browser emulation.

Pure Python Stream Decryptor

Natively reverses SaturnCDN's player playlists and tokenized stream locations in pure Python without launching Chrome or Node processes.

Concurrent HLS Downloader

Fetches fragmented .ts video chunks across multiple worker threads, automatically selects highest bitrate variants, and stitches valid, playable media files.

Dynamic Multi-Domain Failover

Connects to official mirror lists to auto-discover active domains and select the fastest server, shielding your integration from DNS blocks and ISP filters.

Pythonic Interface & CLI

Natural indexing like anime[1], rich objects (Anime, Episodio, Server), and full terminal command-line tool with clean cancellation.
